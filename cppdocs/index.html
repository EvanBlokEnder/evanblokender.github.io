Universal ImGui C++ Extensions

Create small C++ extension files from the Extensions tab, save them as .cpp, and use them as native add-ons for game-specific hooks, tools, UI buttons, sliders, and tooltips.

Where Files Go

hi.

Extension Shape

An extension can expose lifecycle functions. A loader or bridge can call these after the extension source is compiled into the native mod.

#include "BNMResolve.hpp"
#include "Settings.hpp"

extern "C" void OnExtensionLoad() {
    // Set up hooks, find classes, or create state here.
}

extern "C" void OnExtensionTick() {
    // Per-frame game logic goes here.
}

Choosing A Game

Use the Target Game slider in the Extensions tab to label the extension for Any Game, Gorilla Tag, Project Demigod, or a custom package. The label is saved into the generated file header so you can tell which hooks belong to which game.

Adding Buttons, Sliders, And Tooltips

Use normal ImGui controls inside your extension UI function or bridge. Give every risky action a clear tooltip so the menu explains what it will do before you press it.

void DrawMyExtensionUi() {
    static bool enabled = false;
    if (ImGui::Checkbox("Enable Hook", &enabled) && enabled) {
        OnExtensionLoad();
    }
    if (ImGui::IsItemHovered()) {
        ImGui::SetTooltip("Turns on this extension hook for the selected game.");
    }

    static float power = 1.0f;
    ImGui::SliderFloat("Power", &power, 0.0f, 10.0f);
}

Running Extensions

The Run button saves the current source and tries to send it to an in-game object named CppExtensionRunner, ExtensionRunner, or UniversalExtensionRunner with a RunCppExtension(string source) receiver. Native C++ hooks still need to be compiled into the mod or handled by your own bridge.

Hooking Tips

  • Keep game-specific class lookups behind the selected target game check.
  • Prefer BNM::Class, BNM::Method, and typed wrappers from BNMResolve.hpp.
  • Guard hooks and object edits with null checks so scene changes do not crash the game.
  • Save often from the Extensions tab; the file list reloads from disk.
